# paint · 本地画室

一个 macOS 风格的轻量本地绘图应用，使用原生 HTML、CSS 和 JavaScript，无需构建或安装依赖。

在线使用：https://moxiaofei.github.io/paint/

支持手机和平板横竖屏：手机工具栏分两排，颜色可横向滑动；支持手指或触控笔绘画。用底部滑块缩放，选择“移动”工具后可拖动画布；点击“适合窗口”恢复全图，之后会随屏幕旋转自动适配。手动缩放后会保留缩放比例。移动工具快捷键为 H。

双击 `启动画图.cmd` 或 `index.html`，在 Edge、Chrome 等现代浏览器中运行。不需要联网、安装依赖或启动服务器。

支持画笔、橡皮、连通区域填充、取色、文字、直线、矩形、椭圆、自定义颜色、线宽、实心形状、撤销重做（最多 20 步）、图片导入、PNG 导出、画布尺寸和视图缩放。

快捷键：B 画笔、E 橡皮、F 填充、I 取色、T 文字、L 直线、R 矩形、O 椭圆；Ctrl+Z 撤销、Ctrl+Y / Ctrl+Shift+Z 重做、Ctrl+S 保存。

在画布区域使用鼠标滚轮缩放（10%–400%），向上放大、向下缩小。以鼠标所在位置为缩放中心，靠近画布边缘时受滚动边界约束。放大后可用滚动条移动视图，也可以点击“适合窗口”恢复全图。

这是仿微软画图交互的独立本地 Web 应用，不是微软官方软件。图片在浏览器本地处理，不上传。关闭前请保存 PNG；刷新不会自动恢复作品。缩小画布会裁切超出的内容，可撤销恢复。导入图片限制 1600 万像素。

## 保存软件与作品

GitHub 仓库用于备份应用代码。绘画作品请点击“导出图片”保存为 PNG；如需在 GitHub 备份作品，可在仓库创建 `artworks/` 文件夹并上传 PNG。应用不会自动同步作品到 GitHub。

手机端第一行是文件菜单与五个常用工具，其余工具在第二行。点击颜色圆圈展开调色板，点击空白处或关闭按钮收起。文件菜单包含新建、打开图片、导出 PNG、保存画布，以及撤销和重做。“保存画布到本机”会在当前浏览器保留一份画布快照，可从菜单“恢复已保存画布”恢复；再次保存会替换上一份。它不跨设备同步，清理浏览器数据会丢失，请同时导出 PNG 备份。

从 GitHub 下载代码：点击 Code → Download ZIP，解压后双击 `index.html` 即可运行。
